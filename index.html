About Me

The person behind the pixels.

Hey there, I'm LuxeVisuals — my real name is Mike. I've been a UI designer since February 2nd, 2026, and I've worked with a handful of clients so far, mostly building UI for Roblox. I've actually been scripting for around four years now, maybe more — I've honestly lost track — so I know a lot more about scripting than I do UI design.
